# Sorting in non-increasing order

Read `n` integers and print them from the largest to the smallest.

## Input
- Line 1: `n` (1 ≤ n ≤ 1000).
- Line 2: `n` integers `a_i` (|a_i| ≤ 10^9), separated by spaces.

## Output
One line: the `n` integers in non-increasing order, separated by single spaces.

## Example
Input
```
5
3 -1 7 3 0
```
Output
```
7 3 3 0 -1
```

## Limits
Time limit: 2 seconds. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.

The lab constraints and their deductions are in `constraints.json`.
